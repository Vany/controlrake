🏛️ Architecture Overview

The Default Instance Architecture allows components to have a "default" instance that doesn't require an explicit instance ID. This simplifies usage for singleton-style components while maintaining flexibility for multi-instance components.

📋 Component Support Matrix

✅ Default Instance Supported

  • Clock - System timer/clock
  • HTTP - Web server interface
  • Twitch - IRC client connection
await system.spawn("clock"); // Creates clock:

❌ Default Instance NOT Supported

  • Button - Interactive UI elements
await system.spawn("button", "my-btn"); // Required!
